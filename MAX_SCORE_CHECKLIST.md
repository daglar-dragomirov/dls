# Проверка критериев NLP — 20 баллов

| Критерий | Баллы | Где проверять |
| --- | ---: | --- |
| Сильный baseline | 4 | `models.py`, `official_metrics.json`, раздел baseline в отчёте |
| Агент с возможностью поиска | 8 | `agent.py`: `public_web_search`, `search_card_evidence`, `retrieve_similar_train_examples`; реальный аудит, трассы и UI |
| Прирост над baseline или серьёзный отрицательный результат | 8 | train-only подбор веса, абляция на одном eval, per-class метрики и разбор ошибок в `final_report.md` |

Дополнительно сделано:

- официальный датасет вместо синтетической замены;
- сохранены три класса `0.0/0.1/1.0` без бинаризации;
- eval не участвует в настройке;
- retrieval использует только размеченный train;
- Instructor обеспечивает schema-first LLM output;
- для нового поиска есть отдельная проверка `scripts/audit_live_agent.py`; фактический статус смотрите в `reports/live_agent_audit.json`;
- пакетный API, русскоязычный интерфейс, тесты и Railway-деплой;
- фиксированный seed и полностью воспроизводимый CLI.

## Границы проверки

Таблица сопоставляет код критериям, но не гарантирует 20/20. Июльский experiment
и новая демонстрация — разные версии: нельзя переносить метрики одной на другую.
Новая версия устраняет скрытый fallback, даёт LLM выбор поиска и передаёт
веб-доказательства в решение. Доступность внешнего API проверяется отдельно.
Instructor проверяет схему, а не истинность ответа. Отрицательный результат
по accuracy сохранён; прирост над baseline не заявляется.
